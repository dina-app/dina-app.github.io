DinaSheet for Salesforce

A focused spreadsheet workspace for Salesforce data. Run SOQL queries and reports, import local CSV or Excel files, edit supported object records, and review exact changes before sending a confirmed update to Salesforce.

DinaSheet is an independent product and is not affiliated with, endorsed by, or sponsored by Salesforce.

Spreadsheet Workflows for Salesforce

Query and reports

Run SOQL, browse objects, and open Salesforce reports in a familiar multi-tab grid.

Local file import

Open CSV and Excel files locally in the browser without uploading them to the developer.

Type-aware editing

Edit supported object fields inline with validation based on Salesforce schema information.

Reviewed write-back

Inspect field-level changes and explicitly confirm selected rows before Salesforce updates run.

Update audit and rollback

Review bounded, per-organization update receipts and prepare prior values for a separately confirmed rollback update.

Export

Copy or download spreadsheet data for use in your own workflow.

How It Works

  • DinaSheet reads the active Salesforce session cookie locally and calls only the selected Salesforce organization over HTTPS.
  • The Salesforce session cookie, cookie domain, and authorization header never leave the Chrome extension.
  • Preferences and bounded, per-organization update receipts stay in Chrome extension storage on the user's device; workbook files and sheet snapshots are not persisted.
  • There are no ads, analytics, telemetry, remotely hosted executable code, or developer-operated data servers.

Permissions

  • cookies: reads the existing Salesforce session cookie locally for user-requested Salesforce API calls.
  • storage: stores preferences and bounded, per-organization update receipts used for audit and rollback.
  • Salesforce host access: discovers the signed-in org and calls its APIs for schema, SOQL, reports, and confirmed record updates.
