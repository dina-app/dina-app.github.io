Local by design

  • DinaSheet reads the active Salesforce session cookie locally and calls only the selected Salesforce organization over HTTPS.
  • The Salesforce session cookie, cookie domain, and authorization header never leave the extension.
  • Preferences and bounded per-org update receipts stay in Chrome storage; workbook files and sheet snapshots are not persisted.
  • There are no ads, analytics, telemetry, remotely hosted executable code, external messaging, or developer-operated data servers.

Permissions

  • cookies: reads the existing Salesforce session cookie locally for user-requested API calls.
  • storage: stores preferences and bounded per-org update receipts used for audit and rollback.
  • Salesforce host access: discovers signed-in orgs and calls their APIs for schema, SOQL, reports, and confirmed record updates.
