DinaSheet for Salesforce

Salesforce データに特化したスプレッドシートワークスペースです。SOQL ファイルをフォルダーに保存し、Query・リストビュー・レポートを Favorites に整理してダウンロードでき、更新前には正確な変更内容を確認できます。

DinaSheet は独立した製品であり、Salesforce との提携、Salesforce による承認または後援を受けていません。

Chrome ウェブストアからインストール ユーザーマニュアルを読む プライバシーポリシー（英語）

Salesforce 向けスプレッドシートワークフロー

組織を確認して起動

現在の Salesforce タブと、ほかのログイン済み組織を確認してから、選択したセッションのシートを開きます。

保存できるクエリ

組織ごとの Query フォルダーに SOQL ファイルを保存・編集し、ライブ Salesforce ビューとして再度開けます。

Favorites フォルダー

Query ファイル、オブジェクトのリストビュー、レポートを組織ごとの Favorites に整理し、すぐに開けます。

柔軟なダウンロード

1 件の Favorite を CSV または Excel で、Favorites フォルダー全体を ZIP または複数シートの Excel で保存できます。

オブジェクトとレポート

Salesforce のリストビューとレポートを複数シートのグリッドで参照でき、大規模レポートのワークブック取得にも対応します。

ローカルファイルの読み込み

CSV・Excel ファイルを開発者へアップロードせず、ブラウザー内でローカルに開きます。

型を考慮した編集

Salesforce スキーマ情報に基づく検証を使って、対応するオブジェクト項目を直接編集します。

確認付き更新

項目ごとの変更前・変更後の値を確認し、選択した行を明示的に確定してから更新します。

監査とロールバック

組織ごとに上限付きで保存された更新記録を確認し、以前の値を別途確認するロールバック更新として準備します。

意図しない更新を防ぐフロー

読み込む

保存済み Query、Favorite、リストビュー、レポート、またはローカルの CSV・Excel ファイルを開きます。

確認する

対応する行を編集し、変更項目カードですべての変更値を確認します。

確定する

DinaSheet が Salesforce に更新を送る前に、対象レコードと値を確定します。

ローカル処理を重視

  • DinaSheet は現在の Salesforce セッション Cookie をローカルで読み取り、選択した Salesforce 組織だけに HTTPS でアクセスします。
  • Salesforce セッション Cookie、Cookie ドメイン、認証ヘッダーが拡張機能の外へ送信されることはありません。
  • 設定、組織ごとの Query 定義、上限付き Favorites メタデータ、上限付き更新記録は Chrome ストレージに保存されます。Salesforce の結果行、読み込んだファイル内容、ワークブックスナップショットは保存されません。
  • 広告、分析、テレメトリー、外部ホストの実行可能コード、外部メッセージング、開発者運営のデータサーバーはありません。

権限

  • cookies：ユーザーが要求した API 呼び出しのため、既存の Salesforce セッション Cookie をローカルで読み取ります。
  • storage：設定、組織ごとの Query ファイル・フォルダー定義、1 組織あたり最大 30 の Favorites フォルダーと 100 件のショートカット、監査・ロールバック用の上限付き更新記録を保存します。
  • Salesforce ホストアクセス：ログイン済み組織を検出し、スキーマ、SOQL、レポート、確認済みレコード更新のために API を呼び出します。
