Independent Chrome extension

Agent for Salesforce

An independent Chrome side-panel assistant for Salesforce administrators, developers, and consultants. Chat with AI, read the org context you choose, and run Salesforce tools only with your permission.

Dina Agent is in a closed pilot. Paid billing is not live and no public subscription is currently available.

View planned pricing Contact support

Features

A focused assistant beside Salesforce

Dina Agent stays in the Chrome side panel while you work in Salesforce. It helps you understand the current org, ask informed questions, and use approved tools without turning the AI into an autonomous administrator.

AI chat

Ask questions, investigate an issue, and get explanations while remaining in the Salesforce workflow.

Selected org context

Use the active Salesforce page and the org, object, schema, or metadata context you choose for more relevant assistance.

User-permitted tools

Run supported Salesforce tools only after the user allows the requested action. Existing review and confirmation steps remain in control.

Professional workflows

Support investigation and review work across metadata, data, org configuration, permissions, APIs, exports, and monitoring.

Salesforce authentication credentials are not included in AI chat requests. Consequential Salesforce actions remain subject to user review and permission.
